# Contributor Covenant Code of Conduct

## Our Pledge

We commit to making participation in this project harassment-free for everyone.

## Our Standards

- Show empathy and respect.
- Accept constructive feedback.
- Focus on the health of the community.

## Enforcement

Report unacceptable behavior to project maintainers through private channels.

## Scope

This policy applies within project spaces and in public representation contexts.

## Attribution

This Code of Conduct is adapted from the Contributor Covenant, version 2.1.
