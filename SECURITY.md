# Security Policy

## Supported Version

Current active branch is supported for security fixes.

## Reporting a Vulnerability

Please report vulnerabilities privately and include:
- affected component/path
- reproduction steps
- impact assessment

Do not disclose exploitable details publicly before a fix is available.

## Security Baselines

- Application-level key encryption
- Tenant isolation checks
- Idempotent write handling
- Retention/deletion workflow support
- Audit logging for critical actions
